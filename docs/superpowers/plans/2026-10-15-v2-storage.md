# BentiFiles V2.0 Storage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Encrypt every stored document, purge files of archived projects after 7 calendar days, audit file access, and let customers store documents in their own Google Drive.

**Architecture:** A storage layer (`backend/src/services/storage/`) hides where bytes live behind a `StorageDriver` interface with two implementations: `R2EncryptedDriver` (envelope encryption, AES-256-GCM, per-file DEK wrapped by a master KEK from env) and `GoogleDriveDriver` (Drive REST v3 via axios, `drive.file` scope). Controllers only call `storeFile` / `readFile`. A separate worker purges R2 objects of archived/deleted projects. Delivery is in three independently shippable phases.

**Tech Stack:** Node 20 + Express 5 + TypeScript (strict, `exactOptionalPropertyTypes`, `noUncheckedIndexedAccess`), Prisma 6 / PostgreSQL, `@aws-sdk/client-s3` (R2), axios, Vitest 4, Next.js 16 frontend.

**Spec:** `docs/superpowers/specs/2026-10-15-v2-storage-design.md`

## Global Constraints

- Cipher: AES-256-GCM, 12-byte random IV per operation, 16-byte tag. One 32-byte DEK per file from `crypto.randomBytes`.
- KEK env: `STORAGE_MASTER_KEY_V<n>` (32 bytes, base64) and `STORAGE_MASTER_KEY_CURRENT=<n>`. Backend and workers refuse to start if the current KEK is missing or not 32 bytes.
- R2 object key = random UUID with no extension; `ContentType` = `application/octet-stream`; no user metadata on the object.
- Uploads are never written to disk (`multer.memoryStorage()`), 10 MB limit unchanged.
- Purge: 7 calendar days after `archivedAt`; `DELETED` projects purged on the next run; Drive files are never deleted by us; warning email to project ADMINs 1 day before.
- Google scope: `drive.file` only (plus `openid email` to show which account is connected).
- Drive destination precedence per upload: Office subscription connection → creator's own connection → R2.
- Any Drive failure on upload falls back to encrypted R2. An upload is never lost.
- Code style: match surrounding files (Portuguese user-facing messages, English code identifiers, `logInfo/logError` from `utils/logger` in new services).
- Commit message style: `Feat: ...`, `Test: ...`, `Docs: ...`, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Migrations are applied manually (`npx prisma migrate deploy` with `DIRECT_URL`); the deploy pipeline does not run them.

## Review Focus

1. **Rows written before the migration script runs** (`encryptedDek` null, plaintext `originalName`) must still download and display correctly → Task 3 (legacy read) and Task 1 (`decryptField` passthrough).
2. **File names with accents/emoji** (`Certidão de nascimento 👶.pdf`) must round-trip through `encryptField` byte-for-byte → Task 1.
3. **Unarchive after the warning email but before the purge** must cancel the purge, and re-archiving starts a fresh 7 days → Task 8 (controller resets both columns) and Task 9 (selection ignores projects with `archivedAt` null).
4. **Drive quota full on every upload** must email the owner once, not on every upload → Task 13.
5. **Download of a purged file or one deleted from Drive** must answer 410 with a clear message, and the project ZIP must skip it instead of failing → Task 6 and Task 13.

```ts
// backend/src/services/storage/envelopeCrypto.ts
import crypto from 'crypto';

const ALGORITHM = 'aes-256-gcm';
const IV_LENGTH = 12;
const TAG_LENGTH = 16;
const KEY_LENGTH = 32;
const FIELD_PREFIX = 'enc:v';

export interface EncryptionMeta {
    iv: string;
    authTag: string;
    encryptedDek: string;
    keyVersion: number;
}

export interface EncryptedBlob extends EncryptionMeta {
    ciphertext: Buffer;
}

export const getCurrentKeyVersion = (): number => {
    const raw = process.env.STORAGE_MASTER_KEY_CURRENT;
    const version = Number(raw);
    if (!raw || !Number.isInteger(version) || version < 1) {
        throw new Error('STORAGE_MASTER_KEY_CURRENT deve ser um inteiro >= 1');
    }
    return version;
};

const loadKek = (version: number): Buffer => {
    const name = `STORAGE_MASTER_KEY_V${version}`;
    const raw = process.env[name];
    if (!raw) throw new Error(`${name} nao configurada`);
    const key = Buffer.from(raw, 'base64');
    if (key.length !== KEY_LENGTH) throw new Error(`${name} deve ter 32 bytes em base64`);
    return key;
};

export const assertStorageKeysConfigured = (): void => {
    loadKek(getCurrentKeyVersion());
};

// iv | tag | ciphertext, usado para a DEK e para campos curtos.
const seal = (key: Buffer, plaintext: Buffer): Buffer => {
    const iv = crypto.randomBytes(IV_LENGTH);
    const cipher = crypto.createCipheriv(ALGORITHM, key, iv);
    const ciphertext = Buffer.concat([cipher.update(plaintext), cipher.final()]);
    return Buffer.concat([iv, cipher.getAuthTag(), ciphertext]);
};

const open = (key: Buffer, packed: Buffer): Buffer => {
    const iv = packed.subarray(0, IV_LENGTH);
    const tag = packed.subarray(IV_LENGTH, IV_LENGTH + TAG_LENGTH);
    const ciphertext = packed.subarray(IV_LENGTH + TAG_LENGTH);
    const decipher = crypto.createDecipheriv(ALGORITHM, key, iv);
    decipher.setAuthTag(tag);
    return Buffer.concat([decipher.update(ciphertext), decipher.final()]);
};

export const encryptBuffer = (plaintext: Buffer): EncryptedBlob => {
    const keyVersion = getCurrentKeyVersion();
    const dek = crypto.randomBytes(KEY_LENGTH);
    const iv = crypto.randomBytes(IV_LENGTH);
    const cipher = crypto.createCipheriv(ALGORITHM, dek, iv);
    const ciphertext = Buffer.concat([cipher.update(plaintext), cipher.final()]);

    return {
        ciphertext,
        iv: iv.toString('base64'),
        authTag: cipher.getAuthTag().toString('base64'),
        encryptedDek: seal(loadKek(keyVersion), dek).toString('base64'),
        keyVersion,
    };
};

export const decryptBuffer = (ciphertext: Buffer, meta: EncryptionMeta): Buffer => {
    const dek = open(loadKek(meta.keyVersion), Buffer.from(meta.encryptedDek, 'base64'));
    const decipher = crypto.createDecipheriv(ALGORITHM, dek, Buffer.from(meta.iv, 'base64'));
    decipher.setAuthTag(Buffer.from(meta.authTag, 'base64'));
    return Buffer.concat([decipher.update(ciphertext), decipher.final()]);
};

export const encryptField = (value: string): string => {
    const version = getCurrentKeyVersion();
    const packed = seal(loadKek(version), Buffer.from(value, 'utf8'));
    return `${FIELD_PREFIX}${version}:${packed.toString('base64')}`;
};

export const decryptField = (value: string): string => {
    // Linhas anteriores à migração ainda guardam texto puro.
    if (!value.startsWith(FIELD_PREFIX)) return value;
    const separator = value.indexOf(':', FIELD_PREFIX.length);
    const version = Number(value.slice(FIELD_PREFIX.length, separator));
    const packed = Buffer.from(value.slice(separator + 1), 'base64');
    return open(loadKek(version), packed).toString('utf8');
};
```

```ts
const requireBucket = (): string => {
    const bucketName = process.env.R2_BUCKET_NAME;
    if (!bucketName) throw new Error("R2_BUCKET_NAME not defined in environment");
    return bucketName;
};

export const putObject = async (key: string, body: Buffer): Promise<void> => {
    await r2.send(new PutObjectCommand({
        Bucket: requireBucket(),
        Key: key,
        Body: body,
        ContentType: 'application/octet-stream',
    }));
};

export const getObject = async (key: string): Promise<Buffer> => {
    const response = await r2.send(new GetObjectCommand({ Bucket: requireBucket(), Key: key }));
    if (!response.Body) throw new Error("Empty response body from R2");
```

```ts
// backend/src/services/storage/r2EncryptedDriver.ts
import crypto from 'crypto';

import { deleteObject, getObject, putObject } from '../r2Service';
import { decryptBuffer, encryptBuffer } from './envelopeCrypto';
import { StorageDriver, StorageError, StoredFileRef } from './types';

const isMissingObject = (error: unknown) =>
    error instanceof Error && (error.name === 'NoSuchKey' || error.name === 'NotFound');

export const r2EncryptedDriver: StorageDriver = {
    async put({ buffer }) {
        const blob = encryptBuffer(buffer);
        const storageRef = crypto.randomUUID();
        await putObject(storageRef, blob.ciphertext);

        return {
            storageProvider: 'R2',
            storageRef,
            encryptedDek: blob.encryptedDek,
            iv: blob.iv,
            authTag: blob.authTag,
            keyVersion: blob.keyVersion,
            storageConnectionId: null,
        };
    },

    async get(file: StoredFileRef) {
        if (file.purgedAt) throw new StorageError('PURGED', 'Arquivo expirado');

        let raw: Buffer;
        try {
            raw = await getObject(file.storageRef);
        } catch (error) {
            if (isMissingObject(error)) throw new StorageError('NOT_FOUND', 'Arquivo nao encontrado');
            throw error;
        }

        // Arquivos gravados antes da migração não têm DEK e estão em texto puro.
        if (!file.encryptedDek || !file.iv || !file.authTag || file.keyVersion === null) return raw;

        return decryptBuffer(raw, {
            encryptedDek: file.encryptedDek,
            iv: file.iv,
            authTag: file.authTag,
            keyVersion: file.keyVersion,
        });
    },

    async delete(file: StoredFileRef) {
        await deleteObject(file.storageRef);
    },
};
```

```ts
import { fromBuffer } from 'file-type';

const ALLOWED_MIME_TYPES = [
    'image/jpeg',
    'image/png',
    'application/pdf',
    'application/vnd.openxmlformats-officedocument.wordprocessingml.document',
];

export const validateFileSignature = async (req: Request, res: Response, next: NextFunction) => {
    try {
        const file = req.file;

        if (!file) {
            return next();
        }

        const typeInfo = await fromBuffer(file.buffer);

        if (!typeInfo) {
            console.error(`[BinaryValidator] Failed to detect binary signature for ${file.originalname}`);
            return res.status(400).json({
                success: false,
                message: 'Assinatura do arquivo invalida ou arquivo corrompido.',
            });
        }

        console.log(`[BinaryValidator] Checking ${file.originalname}: declared=${file.mimetype} detected=${typeInfo.mime}`);

        if (!ALLOWED_MIME_TYPES.includes(typeInfo.mime)) {
            console.warn(`[BinaryValidator] Blocked file type: ${typeInfo.mime}`);
            return res.status(400).json({
                success: false,
                message: `Tipo de arquivo nao permitido (${typeInfo.mime}).`,
            });
        }

        if (file.mimetype !== typeInfo.mime) {
            console.warn(`[BinaryValidator] MIME mismatch: header=${file.mimetype} binary=${typeInfo.mime}`);
        }

        next();
    } catch (error) {
        console.error('[BinaryValidator] Internal error:', error);
        res.status(500).json({ message: 'Erro interno ao validar integridade do arquivo.' });
    }
```

```ts
// backend/src/scripts/migrateEncryptStorage.ts
import crypto from 'crypto';
import dotenv from 'dotenv';

import prisma from '../prisma';
import { deleteObject, getObject, putObject } from '../services/r2Service';
import { assertStorageKeysConfigured, decryptBuffer, encryptBuffer, encryptField } from '../services/storage/envelopeCrypto';
import { logError, logInfo } from '../utils/logger';

dotenv.config();

const BATCH_SIZE = 50;

const migrateOne = async (file: { id: string; storageRef: string; originalName: string }) => {
    const original = await getObject(file.storageRef);
    const blob = encryptBuffer(original);
    const newRef = crypto.randomUUID();

    await putObject(newRef, blob.ciphertext);

    // Confere o que foi gravado antes de apagar o original.
    const roundTrip = decryptBuffer(await getObject(newRef), blob);
    if (!roundTrip.equals(original)) {
        await deleteObject(newRef);
        throw new Error('Verificacao de ida e volta falhou');
    }

    await prisma.file.update({
        where: { id: file.id },
        data: {
            filename: newRef,
            storageRef: newRef,
            encryptedDek: blob.encryptedDek,
            iv: blob.iv,
            authTag: blob.authTag,
            keyVersion: blob.keyVersion,
            originalName: file.originalName.startsWith('enc:v') ? file.originalName : encryptField(file.originalName),
        },
    });

    await deleteObject(file.storageRef);
};

const run = async () => {
    assertStorageKeysConfigured();
    const failedIds = new Set<string>();
    let migrated = 0;

    while (true) {
        const batch = await prisma.file.findMany({
            where: { storageProvider: 'R2', encryptedDek: null, purgedAt: null, id: { notIn: [...failedIds] } },
            select: { id: true, storageRef: true, originalName: true },
            take: BATCH_SIZE,
        });
        if (batch.length === 0) break;

        for (const file of batch) {
            try {
                await migrateOne(file);
                migrated += 1;
            } catch (error) {
                failedIds.add(file.id);
                logError('Storage migration failed for file', error, { fileId: file.id });
            }
        }
        logInfo('Storage migration progress', { migrated, failed: failedIds.size });
    }

    logInfo('Storage migration finished', { migrated, failed: failedIds.size, failedIds: [...failedIds] });
    if (failedIds.size > 0) process.exitCode = 1;
};

run()
    .catch((error) => {
        logError('Storage migration fatal error', error);
        process.exitCode = 1;
    })
    .finally(() => prisma.$disconnect());
```

```ts
// backend/src/services/storagePurgeService.ts
import type { Prisma } from '@prisma/client';

import prisma from '../prisma';
import { sendProjectPurgeWarningEmail } from './emailService';
import { deleteStoredFile } from './storage';
import { logError, logInfo } from '../utils/logger';

export const PURGE_AFTER_DAYS = 7;
export const WARN_AFTER_DAYS = 6;
const DAY_MS = 24 * 60 * 60 * 1000;
const DEFAULT_BATCH_SIZE = 100;

const daysBefore = (now: Date, days: number) => new Date(now.getTime() - days * DAY_MS);

export const purgeableFilesWhere = (now: Date): Prisma.FileWhereInput => ({
    purgedAt: null,
    storageProvider: 'R2',
    project: {
        OR: [
            { status: 'ARCHIVED', archivedAt: { not: null, lte: daysBefore(now, PURGE_AFTER_DAYS) } },
            { status: 'DELETED' },
        ],
    },
});

export const warnableProjectsWhere = (now: Date): Prisma.ProjectWhereInput => ({
    status: 'ARCHIVED',
    archivedAt: { lte: daysBefore(now, WARN_AFTER_DAYS), gt: daysBefore(now, PURGE_AFTER_DAYS) },
    purgeWarningSentAt: null,
});

const sendWarnings = async (now: Date): Promise<number> => {
    const projects = await prisma.project.findMany({
        where: warnableProjectsWhere(now),
        select: {
            id: true,
            name: true,
            archivedAt: true,
            members: { where: { role: 'ADMIN' }, select: { user: { select: { email: true, name: true } } } },
        },
    });

    for (const project of projects) {
        if (!project.archivedAt) continue;
        const purgeAt = new Date(project.archivedAt.getTime() + PURGE_AFTER_DAYS * DAY_MS);
        for (const member of project.members) {
            await sendProjectPurgeWarningEmail({
                email: member.user.email,
                name: member.user.name,
                projectName: project.name,
                projectId: project.id,
                purgeAt,
            });
        }
        await prisma.project.update({ where: { id: project.id }, data: { purgeWarningSentAt: now } });
    }

    return projects.length;
};

const purgeFiles = async (now: Date, batchSize: number): Promise<{ purged: number; failed: number }> => {
    const failedIds: string[] = [];
    let purged = 0;

    while (true) {
        const where: Prisma.FileWhereInput = failedIds.length > 0
            ? { ...purgeableFilesWhere(now), id: { notIn: failedIds } }
            : purgeableFilesWhere(now);
        const files = await prisma.file.findMany({ where, take: batchSize });
        if (files.length === 0) break;

        for (const file of files) {
            try {
                await deleteStoredFile(file);
                // Sem a DEK o arquivo é irrecuperável mesmo que o objeto sobreviva em algum backup.
                await prisma.file.update({
                    where: { id: file.id },
                    data: { purgedAt: now, encryptedDek: null, iv: null, authTag: null },
                });
                purged += 1;
            } catch (error) {
                failedIds.push(file.id);
                logError('Storage purge failed for file', error, { fileId: file.id });
            }
        }
    }

    return { purged, failed: failedIds.length };
};

export const runStoragePurgeCycle = async (options: { now?: Date; batchSize?: number } = {}) => {
    const now = options.now ?? new Date();
    const warned = await sendWarnings(now);
    const { purged, failed } = await purgeFiles(now, options.batchSize ?? DEFAULT_BATCH_SIZE);
    logInfo('Storage purge cycle summary', { warned, purged, failed });
    return { warned, purged, failed };
};
```

```ts
import { notifyErrorEventAsync } from '../services/discordAlertService';
import { assertStorageKeysConfigured } from '../services/storage/envelopeCrypto';

import { logError, logInfo, logWarn } from '../utils/logger';

dotenv.config();

const DEFAULT_POLL_MS = 60 * 60 * 1000;
const MAX_CONSECUTIVE_FAILURES = 3;

let isStopping = false;
let wake: (() => void) | null = null;

const requestStop = (signal: string) => {
    if (isStopping) process.exit(1);
    isStopping = true;
    logInfo('Storage purge worker received shutdown signal', { signal });
    wake?.();
};
process.on('SIGTERM', () => requestStop('SIGTERM'));
process.on('SIGINT', () => requestStop('SIGINT'));

const sleep = (ms: number) => new Promise<void>((resolve) => {
    const timer = setTimeout(resolve, ms);
    wake = () => { clearTimeout(timer); resolve(); };
});

// O pooler derruba conexões ociosas entre ciclos de 1h: reconecta se precisar.
const ensureHealthyConnection = async () => {
    try {
        await prisma.$queryRaw`SELECT 1`;
    } catch (error) {
        logWarn('Storage purge worker reconnecting', { error: error instanceof Error ? error.message : String(error) });
        await prisma.$disconnect().catch(() => undefined);
        await prisma.$connect();
    }
};

const run = async () => {
    assertStorageKeysConfigured();
    const mode = (process.env.STORAGE_PURGE_WORKER_MODE || 'once').toLowerCase();
    const pollMs = Number(process.env.STORAGE_PURGE_WORKER_POLL_MS) || DEFAULT_POLL_MS;
    let consecutiveFailures = 0;

    await prisma.$connect();

    while (!isStopping) {
        try {
            await ensureHealthyConnection();
            await runStoragePurgeCycle();
            consecutiveFailures = 0;
        } catch (error) {
            consecutiveFailures += 1;
            logError('Storage purge cycle failed', error, { consecutiveFailures });
            if (mode !== 'loop' || consecutiveFailures >= MAX_CONSECUTIVE_FAILURES) throw error;
        }
        if (mode !== 'loop') break;
        await sleep(pollMs);
    }
};

run()
    .then(async () => {
        await prisma.$disconnect();
        process.exit(0);
    })
    .catch(async (error) => {
        logError('Storage purge worker fatal error', error);
        await notifyErrorEventAsync('Storage purge worker fatal error', error);
        await prisma.$disconnect();
        process.exit(1);
    });
```

```ts
// backend/src/services/storage/googleOAuth.ts
import axios from 'axios';
import crypto from 'crypto';

import { StorageError } from './types';

export const DRIVE_SCOPES = ['openid', 'email', 'https://www.googleapis.com/auth/drive.file'];
const STATE_TTL_MS = 10 * 60 * 1000;
const TOKEN_URL = 'https://oauth2.googleapis.com/token';
const USERINFO_URL = 'https://openidconnect.googleapis.com/v1/userinfo';
const REVOKE_URL = 'https://oauth2.googleapis.com/revoke';

export interface OAuthStatePayload {
    userId: string;
    subscriptionId: string | null;
    returnPath: string;
}

const requireEnv = (name: string): string => {
    const value = process.env[name];
    if (!value) throw new Error(`${name} nao configurada`);
    return value;
};

const sign = (body: string) =>
    crypto.createHmac('sha256', requireEnv('OAUTH_STATE_SECRET')).update(body).digest('base64url');

export const signState = (payload: OAuthStatePayload, now: Date = new Date()): string => {
    const body = Buffer.from(JSON.stringify({ ...payload, exp: now.getTime() + STATE_TTL_MS })).toString('base64url');
    return `${body}.${sign(body)}`;
};

export const verifyState = (state: string, now: Date = new Date()): OAuthStatePayload => {
    const [body, signature] = state.split('.');
    if (!body || !signature) throw new Error('Estado OAuth inválido');
    const expected = Buffer.from(sign(body));
    const received = Buffer.from(signature);
    if (expected.length !== received.length || !crypto.timingSafeEqual(expected, received)) {
        throw new Error('Estado OAuth inválido');
    }
    const { exp, ...payload } = JSON.parse(Buffer.from(body, 'base64url').toString('utf8'));
    if (typeof exp !== 'number' || exp < now.getTime()) throw new Error('Estado OAuth expirado');
    return payload as OAuthStatePayload;
};

export const buildConsentUrl = (state: string): string => {
    const url = new URL('https://accounts.google.com/o/oauth2/v2/auth');
    url.searchParams.set('client_id', requireEnv('GOOGLE_DRIVE_CLIENT_ID'));
    url.searchParams.set('redirect_uri', requireEnv('GOOGLE_DRIVE_REDIRECT_URI'));
    url.searchParams.set('response_type', 'code');
    url.searchParams.set('scope', DRIVE_SCOPES.join(' '));
    url.searchParams.set('access_type', 'offline');
    url.searchParams.set('prompt', 'consent');
    url.searchParams.set('include_granted_scopes', 'true');
    url.searchParams.set('state', state);
    return url.toString();
};

const tokenRequest = (params: Record<string, string>) =>
    axios.post(TOKEN_URL, new URLSearchParams({
        client_id: requireEnv('GOOGLE_DRIVE_CLIENT_ID'),
        client_secret: requireEnv('GOOGLE_DRIVE_CLIENT_SECRET'),
        ...params,
    }).toString(), { headers: { 'Content-Type': 'application/x-www-form-urlencoded' } });

export const exchangeCode = async (code: string) => {
    const { data } = await tokenRequest({
        code,
        grant_type: 'authorization_code',
        redirect_uri: requireEnv('GOOGLE_DRIVE_REDIRECT_URI'),
    });
    if (!data.refresh_token) throw new Error('Google nao devolveu refresh token');

    const userInfo = await axios.get(USERINFO_URL, { headers: { Authorization: `Bearer ${data.access_token}` } });

    return {
        refreshToken: data.refresh_token as string,
        accessToken: data.access_token as string,
        expiresIn: Number(data.expires_in),
        email: userInfo.data.email as string,
    };
};

export const refreshAccessToken = async (refreshToken: string) => {
    try {
        const { data } = await tokenRequest({ refresh_token: refreshToken, grant_type: 'refresh_token' });
        return { accessToken: data.access_token as string, expiresIn: Number(data.expires_in) };
    } catch (error: any) {
        if (error?.response?.data?.error === 'invalid_grant') {
            throw new StorageError('AUTH_REVOKED', 'Acesso ao Google Drive revogado');
        }
        throw new StorageError('UNAVAILABLE', 'Google indisponivel ao renovar o token');
    }
};

export const revokeToken = async (token: string): Promise<void> => {
    await axios.post(REVOKE_URL, new URLSearchParams({ token }).toString(), {
        headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    }).catch(() => undefined);
};
```

```ts
// backend/src/services/storage/googleDriveDriver.ts
import type { StorageConnection } from '@prisma/client';
import axios from 'axios';
import crypto from 'crypto';

import prisma from '../../prisma';
import { decryptField } from './envelopeCrypto';
import { refreshAccessToken } from './googleOAuth';
import { PutInput, StorageDriver, StorageError, StoredFileRef } from './types';

const API = 'https://www.googleapis.com/drive/v3/files';
const UPLOAD_API = 'https://www.googleapis.com/upload/drive/v3/files';
const FOLDER_MIME = 'application/vnd.google-apps.folder';
const MAX_ATTEMPTS = 3;
const BASE_BACKOFF_MS = 500;

type DriveConnection = Pick<StorageConnection, 'id' | 'encryptedRefreshToken' | 'rootFolderId' | 'sharedDriveId'>;

const tokenCache = new Map<string, { token: string; expiresAt: number }>();

export const getAccessToken = async (connection: DriveConnection): Promise<string> => {
    const cached = tokenCache.get(connection.id);
    if (cached && cached.expiresAt - 60_000 > Date.now()) return cached.token;

    const { accessToken, expiresIn } = await refreshAccessToken(decryptField(connection.encryptedRefreshToken));
    tokenCache.set(connection.id, { token: accessToken, expiresAt: Date.now() + expiresIn * 1000 });
    return accessToken;
};

const mapDriveError = (error: any): StorageError | null => {
    if (error instanceof StorageError) return error;
    const status = error?.response?.status;
    const reasons: string[] = (error?.response?.data?.error?.errors ?? []).map((e: any) => e.reason);
    if (status === 404) return new StorageError('NOT_FOUND', 'Arquivo removido do Google Drive');
    if (status === 403 && reasons.includes('storageQuotaExceeded')) return new StorageError('QUOTA', 'Google Drive sem espaço');
    if (status === 401) return new StorageError('AUTH_REVOKED', 'Acesso ao Google Drive revogado');
    return null;
};

const isRetryable = (error: any) => {
    const status = error?.response?.status;
    return status === undefined || status === 429 || status >= 500;
};

const withRetry = async <T>(fn: () => Promise<T>): Promise<T> => {
    for (let attempt = 1; ; attempt += 1) {
        try {
            return await fn();
        } catch (error) {
            const mapped = mapDriveError(error);
            if (mapped) throw mapped;
            if (!isRetryable(error) || attempt >= MAX_ATTEMPTS) {
                throw new StorageError('UNAVAILABLE', 'Google Drive indisponível');
            }
            await new Promise((resolve) => setTimeout(resolve, BASE_BACKOFF_MS * 2 ** (attempt - 1)));
        }
    }
};

export const createDriveFolder = async (accessToken: string, name: string, parentId: string | null): Promise<string> => {
    const { data } = await withRetry(() => axios.post(
        `${API}?supportsAllDrives=true&fields=id`,
        { name, mimeType: FOLDER_MIME, ...(parentId ? { parents: [parentId] } : {}) },
        { headers: { Authorization: `Bearer ${accessToken}` } },
    ));
    return data.id as string;
};

const ensureProjectFolder = async (connection: DriveConnection, accessToken: string, projectId: string): Promise<string> => {
    const existing = await prisma.storageFolder.findUnique({
        where: { connectionId_projectId: { connectionId: connection.id, projectId } },
    });
    if (existing) return existing.folderId;

    const project = await prisma.project.findUnique({ where: { id: projectId }, select: { name: true } });
    const folderId = await createDriveFolder(accessToken, project?.name ?? projectId, connection.rootFolderId);
    await prisma.storageFolder.create({ data: { connectionId: connection.id, projectId, folderId } });
    return folderId;
};

const buildMultipart = (metadata: object, buffer: Buffer, mimetype: string) => {
    const boundary = `bentifiles-${crypto.randomUUID()}`;
    const body = Buffer.concat([
        Buffer.from(`--${boundary}\r\nContent-Type: application/json; charset=UTF-8\r\n\r\n${JSON.stringify(metadata)}\r\n`),
        Buffer.from(`--${boundary}\r\nContent-Type: ${mimetype}\r\n\r\n`),
        buffer,
        Buffer.from(`\r\n--${boundary}--`),
    ]);
    return { body, contentType: `multipart/related; boundary=${boundary}` };
};

export const createGoogleDriveDriver = (connection: DriveConnection): StorageDriver => ({
    async put({ buffer, mimetype, projectId, displayName }: PutInput) {
        const accessToken = await getAccessToken(connection);
        const folderId = await ensureProjectFolder(connection, accessToken, projectId);
        const { body, contentType } = buildMultipart({ name: displayName, parents: [folderId] }, buffer, mimetype);

        const { data } = await withRetry(() => axios.post(
            `${UPLOAD_API}?uploadType=multipart&supportsAllDrives=true&fields=id`,
            body,
            { headers: { Authorization: `Bearer ${accessToken}`, 'Content-Type': contentType }, maxBodyLength: Infinity },
        ));

        return {
            storageProvider: 'GDRIVE',
            storageRef: data.id as string,
            encryptedDek: null,
            iv: null,
            authTag: null,
            keyVersion: null,
            storageConnectionId: connection.id,
        };
    },

    async get(file: StoredFileRef) {
        const accessToken = await getAccessToken(connection);
        const { data } = await withRetry(() => axios.get(
            `${API}/${encodeURIComponent(file.storageRef)}?alt=media&supportsAllDrives=true`,
            { headers: { Authorization: `Bearer ${accessToken}` }, responseType: 'arraybuffer' },
        ));
        return Buffer.from(data);
    },

    async delete() {
        // Arquivos no Drive pertencem ao cliente: nunca apagamos.
    },

    async rename(file: StoredFileRef, name: string) {
        const accessToken = await getAccessToken(connection);
        await withRetry(() => axios.patch(
            `${API}/${encodeURIComponent(file.storageRef)}?supportsAllDrives=true`,
            { name },
            { headers: { Authorization: `Bearer ${accessToken}` } },
        ));
    },
});
```

```ts
// backend/src/services/storage/storageConnectionService.ts
import type { StorageConnection } from '@prisma/client';

import prisma from '../../prisma';
import { sendStorageConnectionAlertEmail } from '../emailService';
import { getOfficeSeatAccessForUser } from '../officeSubscriptionService';
import { StorageError } from './types';

const isUsable = (connection: StorageConnection | null): connection is StorageConnection =>
    Boolean(connection && connection.status === 'ACTIVE' && connection.rootFolderId);

export const resolveConnectionForProject = async (projectId: string): Promise<StorageConnection | null> => {
    const project = await prisma.project.findUnique({ where: { id: projectId }, select: { createdByUserId: true } });
    if (!project) return null;

    const seat = await getOfficeSeatAccessForUser(project.createdByUserId);
    if (seat) {
        const office = await prisma.storageConnection.findUnique({ where: { subscriptionId: seat.subscriptionId } });
        if (isUsable(office)) return office;
    }

    const own = await prisma.storageConnection.findUnique({ where: { userId: project.createdByUserId } });
    return isUsable(own) ? own : null;
};

export const recordConnectionFailure = async (connection: StorageConnection, error: StorageError): Promise<void> => {
    const isNewProblem = connection.lastError !== error.code;

    await prisma.storageConnection.update({
        where: { id: connection.id },
        data: error.code === 'AUTH_REVOKED'
            ? { status: 'REVOKED', lastError: error.code }
            : { lastError: error.code },
    });

    if (!isNewProblem) return;
    if (error.code !== 'AUTH_REVOKED' && error.code !== 'QUOTA' && error.code !== 'UNAVAILABLE') return;

    const owner = await prisma.user.findUnique({ where: { id: connection.connectedByUserId }, select: { email: true, name: true } });
    if (owner) await sendStorageConnectionAlertEmail({ email: owner.email, name: owner.name, reason: error.code });
};

export const clearConnectionFailure = async (connection: StorageConnection): Promise<void> => {
    if (!connection.lastError) return;
    await prisma.storageConnection.update({ where: { id: connection.id }, data: { lastError: null } });
};
```

```ts
import { logError, logWarn } from '../../utils/logger';
import { createGoogleDriveDriver } from './googleDriveDriver';

import { clearConnectionFailure, recordConnectionFailure, resolveConnectionForProject } from './storageConnectionService';

const driverFor = async (file: StoredFileRef): Promise<StorageDriver> => {
    if (file.storageProvider !== 'GDRIVE') return r2EncryptedDriver;

    const connection = file.storageConnectionId
        ? await prisma.storageConnection.findUnique({ where: { id: file.storageConnectionId } })
        : null;
    if (!connection || connection.status !== 'ACTIVE') {
        throw new StorageError('DISCONNECTED', 'Google Drive desconectado');
    }
    return createGoogleDriveDriver(connection);
};

export const storeFile = async (input: PutInput): Promise<StoredObject> => {
    const connection = await resolveConnectionForProject(input.projectId);
    if (!connection) return r2EncryptedDriver.put(input);

    try {
        const stored = await createGoogleDriveDriver(connection).put(input);
        await clearConnectionFailure(connection);
        return stored;
    } catch (error) {
        if (error instanceof StorageError) {
            logWarn('Drive upload failed, falling back to R2', { connectionId: connection.id, code: error.code });
            await recordConnectionFailure(connection, error).catch((e) => logError('Failed to record Drive failure', e));
        } else {
            logError('Unexpected Drive upload error, falling back to R2', error, { connectionId: connection.id });
        }
        return r2EncryptedDriver.put(input);
    }
};

export const readFile = async (file: StoredFileRef): Promise<Buffer> => (await driverFor(file)).get(file);

export const deleteStoredFile = async (file: StoredFileRef): Promise<void> => (await driverFor(file)).delete(file);

export const renameStoredFile = async (file: StoredFileRef, name: string): Promise<void> => {
    const driver = await driverFor(file);
    if (driver.rename) await driver.rename(file, name);
```

```ts
// backend/src/controllers/storageController.ts
import { Response } from 'express';

import { AuthRequest } from '../middleware/auth';
import prisma from '../prisma';
import { getOfficeSeatAccessForUser } from '../services/officeSubscriptionService';
import { decryptField, encryptField } from '../services/storage/envelopeCrypto';
import { createDriveFolder, getAccessToken } from '../services/storage/googleDriveDriver';
import { buildConsentUrl, exchangeCode, revokeToken, signState, verifyState } from '../services/storage/googleOAuth';
import { logError } from '../utils/logger';

type ManageScope = { kind: 'OFFICE'; subscriptionId: string } | { kind: 'USER'; userId: string } | null;

const ALLOWED_RETURN_PATHS = new Set(['/profile', '/subscription']);

const resolveManageScope = async (userId: string): Promise<ManageScope> => {
    const office = await prisma.subscription.findFirst({ where: { ownerId: userId, plan: 'OFFICE' }, select: { id: true } });
    if (office) return { kind: 'OFFICE', subscriptionId: office.id };

    const seat = await getOfficeSeatAccessForUser(userId);
    if (seat) return null; // vaga do escritório: quem conecta é o dono

    return { kind: 'USER', userId };
};

const whereForScope = (scope: NonNullable<ManageScope>) =>
    scope.kind === 'OFFICE' ? { subscriptionId: scope.subscriptionId } : { userId: scope.userId };

const findConnection = (scope: NonNullable<ManageScope>) =>
    prisma.storageConnection.findUnique({ where: whereForScope(scope) });

const publicConnection = (connection: Awaited<ReturnType<typeof findConnection>>) => connection && {
    googleAccountEmail: connection.googleAccountEmail,
    status: connection.status,
    rootFolderId: connection.rootFolderId,
    sharedDriveId: connection.sharedDriveId,
    lastError: connection.lastError,
};

const frontendUrl = () => {
    const url = process.env.FRONTEND_URL || 'http://localhost:3000';
    return url.startsWith('http') ? url : `https://${url}`;
};

export const getConnection = async (req: AuthRequest, res: Response) => {
    const userId = req.user!.userId;
    const scope = await resolveManageScope(userId);
    if (!scope) return res.json({ canManage: false, scope: null, connection: null });
    res.json({ canManage: true, scope: scope.kind, connection: publicConnection(await findConnection(scope)) });
};

export const startGoogleConnect = async (req: AuthRequest, res: Response) => {
    const userId = req.user!.userId;
    const scope = await resolveManageScope(userId);
    if (!scope) return res.status(403).json({ message: 'Apenas o dono da assinatura do escritório pode conectar o Drive.' });

    const requested = typeof req.query.returnPath === 'string' ? req.query.returnPath : '/profile';
    const returnPath = ALLOWED_RETURN_PATHS.has(requested) ? requested : '/profile';
    const state = signState({ userId, subscriptionId: scope.kind === 'OFFICE' ? scope.subscriptionId : null, returnPath });
    res.json({ url: buildConsentUrl(state) });
};

export const googleCallback = async (req: AuthRequest, res: Response) => {
    let returnPath = '/profile';
    try {
        const { code, state } = req.query;
        if (typeof code !== 'string' || typeof state !== 'string') throw new Error('Parametros ausentes');
        const payload = verifyState(state);
        returnPath = payload.returnPath;

        const tokens = await exchangeCode(code);
        const ownerWhere = payload.subscriptionId ? { subscriptionId: payload.subscriptionId } : { userId: payload.userId };
        const data = {
            provider: 'GDRIVE' as const,
            connectedByUserId: payload.userId,
            googleAccountEmail: tokens.email,
            encryptedRefreshToken: encryptField(tokens.refreshToken),
            rootFolderId: null,
            sharedDriveId: null,
            status: 'ACTIVE' as const,
            lastError: null,
        };

        await prisma.storageConnection.upsert({
            where: ownerWhere,
            create: { ...ownerWhere, ...data },
            update: data,
        });
        // Pastas de projeto antigas pertenciam ao Drive anterior.
        const connection = await prisma.storageConnection.findUnique({ where: ownerWhere });
        if (connection) await prisma.storageFolder.deleteMany({ where: { connectionId: connection.id } });

        res.redirect(`${frontendUrl()}${returnPath}?storage=connected`);
    } catch (error) {
        logError('Google Drive connect callback failed', error);
        res.redirect(`${frontendUrl()}${returnPath}?storage=error`);
    }
};

export const getPickerToken = async (req: AuthRequest, res: Response) => {
    const scope = await resolveManageScope(req.user!.userId);
    const connection = scope && await findConnection(scope);
    if (!connection || connection.status !== 'ACTIVE') return res.status(404).json({ message: 'Drive não conectado' });
    res.json({ accessToken: await getAccessToken(connection) });
};

export const setFolder = async (req: AuthRequest, res: Response) => {
    try {
        const scope = await resolveManageScope(req.user!.userId);
        const connection = scope && await findConnection(scope);
        if (!connection || connection.status !== 'ACTIVE') return res.status(404).json({ message: 'Drive não conectado' });

        const { mode, folderId, sharedDriveId } = req.body ?? {};
        let rootFolderId: string;
        let resolvedSharedDrive: string | null = null;

        if (mode === 'create') {
            rootFolderId = await createDriveFolder(await getAccessToken(connection), 'BentiFiles', null);
        } else if (mode === 'picked' && typeof folderId === 'string' && folderId) {
            rootFolderId = folderId;
            resolvedSharedDrive = typeof sharedDriveId === 'string' && sharedDriveId ? sharedDriveId : null;
        } else {
            return res.status(400).json({ message: 'Escolha uma pasta válida' });
        }

        const updated = await prisma.storageConnection.update({
            where: { id: connection.id },
            data: { rootFolderId, sharedDriveId: resolvedSharedDrive },
        });
        await prisma.storageFolder.deleteMany({ where: { connectionId: connection.id } });
        res.json({ connection: publicConnection(updated) });
    } catch (error) {
        logError('Failed to set Drive folder', error);
        res.status(502).json({ message: 'Não foi possível acessar a pasta no Google Drive' });
    }
};

export const disconnect = async (req: AuthRequest, res: Response) => {
    const scope = await resolveManageScope(req.user!.userId);
    const connection = scope && await findConnection(scope);
    if (!connection) return res.status(404).json({ message: 'Drive não conectado' });

    await revokeToken(decryptField(connection.encryptedRefreshToken));
    await prisma.storageConnection.update({ where: { id: connection.id }, data: { status: 'REVOKED', lastError: null } });
    res.json({ success: true });
};
```

Note: disconnect keeps the row (status `REVOKED`) so existing `File.storageConnectionId` references resolve to `DISCONNECTED` (409) instead of losing the link; reconnecting upserts the same row back to `ACTIVE`.

```ts
// frontend/src/lib/storage/googlePicker.ts
declare global {
    interface Window { gapi?: any; google?: any }
}

const loadScript = (src: string) => new Promise<void>((resolve, reject) => {
    if (document.querySelector(`script[src="${src}"]`)) return resolve();
    const script = document.createElement('script');
    script.src = src;
    script.async = true;
    script.onload = () => resolve();
    script.onerror = () => reject(new Error(`Falha ao carregar ${src}`));
    document.body.appendChild(script);
});

export interface PickedFolder {
    folderId: string;
    sharedDriveId: string | null;
}

export const pickDriveFolder = async (accessToken: string): Promise<PickedFolder | null> => {
    await loadScript('https://apis.google.com/js/api.js');
    await new Promise<void>((resolve) => window.gapi.load('picker', () => resolve()));
    const { google } = window;

    return new Promise((resolve) => {
        const view = new google.picker.DocsView(google.picker.ViewId.FOLDERS)
            .setIncludeFolders(true)
            .setSelectFolderEnabled(true)
            .setEnableDrives(true)
            .setMimeTypes('application/vnd.google-apps.folder');

        const picker = new google.picker.PickerBuilder()
            .addView(view)
            .enableFeature(google.picker.Feature.SUPPORT_DRIVES)
            .setOAuthToken(accessToken)
            .setDeveloperKey(process.env.NEXT_PUBLIC_GOOGLE_PICKER_API_KEY)
            .setAppId(process.env.NEXT_PUBLIC_GOOGLE_CLOUD_APP_ID)
            .setTitle('Escolha a pasta onde o BentiFiles vai salvar os documentos')
            .setCallback((data: any) => {
                if (data.action === google.picker.Action.PICKED) {
                    const doc = data.docs?.[0];
                    resolve(doc ? { folderId: doc.id, sharedDriveId: doc.driveId ?? null } : null);
                } else if (data.action === google.picker.Action.CANCEL) {
                    resolve(null);
                }
            })
            .build();
        picker.setVisible(true);
    });
};
```

```tsx
// frontend/src/components/storage/StorageCard.tsx
'use client';

import { useCallback, useEffect, useState } from 'react';
import { useSearchParams } from 'next/navigation';
import { useSession } from 'next-auth/react';
import { HardDrive, Loader2 } from 'lucide-react';
import { toast } from 'sonner';

import { api, getAuthHeaders } from '@/lib/api';
import { pickDriveFolder } from '@/lib/storage/googlePicker';
import styles from './StorageCard.module.scss';

interface ConnectionInfo {
    googleAccountEmail: string;
    status: 'ACTIVE' | 'REVOKED';
    rootFolderId: string | null;
    sharedDriveId: string | null;
    lastError: string | null;
}

interface ConnectionResponse {
    canManage: boolean;
    scope: 'OFFICE' | 'USER' | null;
    connection: ConnectionInfo | null;
}

const ERROR_LABELS: Record<string, string> = {
    QUOTA: 'Seu Drive está sem espaço. Novos documentos estão sendo guardados no BentiFiles.',
    UNAVAILABLE: 'O Google Drive falhou recentemente. Novos documentos foram guardados no BentiFiles.',
    AUTH_REVOKED: 'O acesso ao Drive foi revogado. Reconecte para voltar a salvar lá.',
};

export default function StorageCard({ returnPath }: { returnPath: '/profile' | '/subscription' }) {
    const { data: session } = useSession();
    const searchParams = useSearchParams();
    const [data, setData] = useState<ConnectionResponse | null>(null);
    const [busy, setBusy] = useState(false);
    const headers = getAuthHeaders(session?.user?.token);

    const load = useCallback(async () => {
        const res = await api.get('/api/storage/connection', { headers });
        setData(res.data);
    }, [session?.user?.token]);

    useEffect(() => {
        if (session?.user?.token) load().catch(() => setData(null));
    }, [session?.user?.token, load]);

    useEffect(() => {
        const status = searchParams.get('storage');
        if (status === 'connected') toast.success('Google Drive conectado. Agora escolha a pasta.');
        if (status === 'error') toast.error('Não foi possível conectar o Google Drive.');
    }, [searchParams]);

    if (!data?.canManage) return null;

    const run = async (fn: () => Promise<void>) => {
        setBusy(true);
        try { await fn(); await load(); }
        catch (error: any) { toast.error(error.response?.data?.message || 'Falha na operação com o Google Drive'); }
        finally { setBusy(false); }
    };

    const connect = () => run(async () => {
        const res = await api.get('/api/storage/google/connect', { params: { returnPath }, headers });
        window.location.href = res.data.url;
    });

    const createDefaultFolder = () => run(async () => {
        await api.post('/api/storage/google/folder', { mode: 'create' }, { headers });
        toast.success('Pasta "BentiFiles" criada no seu Drive.');
    });

    const chooseFolder = () => run(async () => {
        const tokenRes = await api.get('/api/storage/google/picker-token', { headers });
        const picked = await pickDriveFolder(tokenRes.data.accessToken);
        if (!picked) return;
        await api.post('/api/storage/google/folder', { mode: 'picked', ...picked }, { headers });
        toast.success('Pasta escolhida.');
    });

    const disconnect = () => run(async () => {
        if (!confirm('Desconectar o Google Drive? Os arquivos já salvos continuam no seu Drive; os novos passam a ser guardados no BentiFiles.')) return;
        await api.delete('/api/storage/google', { headers });
        toast.success('Google Drive desconectado.');
    });

    const connection = data.connection;
    const isActive = connection?.status === 'ACTIVE';

    return (
        <section className={styles.card}>
            <div className={styles.header}>
                <HardDrive size={20} />
                <div>
                    <h2 className={styles.title}>Armazenamento</h2>
                    <p className={styles.subtitle}>
                        {data.scope === 'OFFICE'
                            ? 'Os documentos de todos os projetos do escritório serão salvos neste Drive. Use um Drive compartilhado para o time inteiro ter acesso.'
                            : 'Salve os documentos dos seus projetos no seu próprio Google Drive.'}
                    </p>
                </div>
            </div>

            {!isActive && (
                <>
                    {connection?.status === 'REVOKED' && <p className={styles.warning}>Drive desconectado. Novos documentos estão sendo guardados no BentiFiles.</p>}
                    <button className={styles.primary} onClick={connect} disabled={busy}>
                        {busy ? <Loader2 size={16} className="animate-spin" /> : null} Conectar Google Drive
                    </button>
                </>
            )}

            {isActive && connection && (
                <>
                    <p className={styles.status}>Conectado como <strong>{connection.googleAccountEmail}</strong></p>
                    {connection.lastError && ERROR_LABELS[connection.lastError] && <p className={styles.warning}>{ERROR_LABELS[connection.lastError]}</p>}
                    {!connection.rootFolderId ? (
                        <div className={styles.actions}>
                            <button className={styles.primary} onClick={createDefaultFolder} disabled={busy}>Criar pasta "BentiFiles" no Meu Drive</button>
                            <button className={styles.secondary} onClick={chooseFolder} disabled={busy}>Escolher pasta (inclui Drive compartilhado)</button>
                        </div>
                    ) : (
                        <div className={styles.actions}>
                            <span className={styles.status}>{connection.sharedDriveId ? 'Salvando em um Drive compartilhado' : 'Salvando no Meu Drive'}</span>
                            <button className={styles.secondary} onClick={chooseFolder} disabled={busy}>Trocar pasta</button>
                            <button className={styles.danger} onClick={disconnect} disabled={busy}>Desconectar</button>
                        </div>
                    )}
                </>
            )}
        </section>
    );
}
```
