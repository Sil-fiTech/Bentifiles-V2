Você recebeu um convite quando alguém lhe enviou um **link** (ou um e-mail com o link) para participar de um projeto. Abrir esse link é o primeiro passo para enviar seus documentos.

## Passo a passo

<Steps>

1. **Abra o link do convite.** Ele leva à tela de entrada do Bentifiles.
2. **Se você não tem conta**, crie uma. Veja [Criar conta e entrar](/docs/comecando/criar-conta-e-entrar). **Se já tem**, apenas entre.
3. Assim que a conta estiver pronta, o Bentifiles **processa o convite sozinho** e mostra uma mensagem de confirmação.
4. Você é levado direto à **página do projeto**, onde estão os documentos que precisa enviar.

</Steps>

<Callout type="info" title="Use o mesmo navegador">
O convite fica guardado no navegador até você terminar de entrar ou de confirmar o e-mail. Se você abrir o link num navegador e confirmar a conta em outro, pode ser necessário abrir o link do convite novamente.
</Callout>

## Se aparecer um erro

| Mensagem | O que fazer |
| --- | --- |
| **Convite expirado** | O convite de projeto vale **24 horas**. Peça a quem convidou para gerar um novo. |
| **Convite não encontrado ou inválido** | O link está incompleto ou não é válido. Confira se foi copiado inteiro e, se persistir, peça o link de novo. |
| **Convite já atingiu o limite de uso** | O link já foi usado o máximo de vezes. Peça um novo. |
| **Este projeto está arquivado (somente leitura)** | O projeto foi encerrado e não aceita novos participantes. |
| **Usuário já é membro deste projeto** | Você já entrou antes. Abra o projeto pelo painel. |

## Depois de entrar

Seus projetos ficam sempre no **painel**. Para enviar os arquivos, siga [Enviar um documento](/docs/enviar/enviar-um-documento).
