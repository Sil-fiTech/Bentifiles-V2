Você pode baixar um documento isolado ou todos os documentos do projeto de uma vez.

## Escolher o formato

Os botões de download têm um pequeno menu com duas opções:

| Formato | Resultado |
| --- | --- |
| **PDF** | O arquivo convertido para PDF. É o formato padrão. |
| **Original** | O arquivo exatamente como foi enviado (por exemplo, a foto em JPG). |

## Baixar um documento

No checklist da pessoa, ao lado de **Ver**, clique em **Baixar PDF**. Para escolher o formato, abra o menu do botão e selecione **PDF** ou **Original**.

## Baixar o projeto inteiro (ZIP)

<Steps>

1. No cabeçalho da página do projeto, localize o botão **ZIP em PDF**. Ele aparece só para quem administra o projeto.
2. Se quiser os arquivos como foram enviados, abra o menu do botão e escolha **Original**.
3. Aguarde. O sistema reúne os arquivos e baixa um único arquivo ZIP.

</Steps>

Dentro do ZIP, cada arquivo recebe um nome que identifica o **tipo de documento** e a **pessoa** que enviou, seguido do nome original, o que facilita organizar depois.

<Callout type="info">
A conversão para PDF acontece no servidor e pode levar alguns segundos, principalmente em projetos com muitos documentos.
</Callout>
