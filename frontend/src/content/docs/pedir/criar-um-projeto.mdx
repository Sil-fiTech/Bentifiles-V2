Um **projeto** é o espaço de uma coleta de documentos: pode ser um cliente, um processo seletivo, um contrato ou um setor. Cada projeto tem os seus próprios participantes e a sua própria lista de documentos pedidos.

## O que você precisa

Criar projetos exige uma **assinatura ativa** (ou o período de teste do plano). Sem ela, ao tentar criar, o Bentifiles avisa que a assinatura é necessária e leva você à página de planos. Veja [Planos e assinatura](/docs/conta/planos-e-assinatura).

## Criar o projeto

<Steps>

1. No menu superior, clique em **Novo Projeto**. No celular, abra o menu (☰) primeiro. Se ainda não tem nenhum projeto, o painel também mostra o botão **Criar o primeiro projeto**.
2. O projeto é criado **imediatamente**, com o nome provisório **Novo Projeto**, e você é levado à página dele.
3. Troque o nome: ao lado do título há um ícone de lápis (**Renomear Projeto**). Digite o novo nome e confirme com o ícone de visto ou com **Enter**. Para desistir, use o ícone de cancelar.

</Steps>

<Callout type="warning" title="Dê um nome logo">
Como o projeto nasce chamado "Novo Projeto", crie um por vez e renomeie em seguida. Vários projetos com o mesmo nome ficam difíceis de distinguir no painel.
</Callout>

## O que vem depois

Um projeto recém-criado ainda está vazio. Para ele funcionar, faça nesta ordem:

1. [Defina os documentos pedidos](/docs/pedir/definir-documentos-obrigatorios).
2. [Convide as pessoas](/docs/pedir/convidar-pessoas).
3. [Acompanhe o progresso](/docs/pedir/acompanhar-o-projeto) e [revise os envios](/docs/pedir/revisar-documentos).

## Status do projeto

Um projeto pode estar **Ativo** ou **Arquivado**. Projetos arquivados ficam somente para consulta. Veja [Membros, arquivar e excluir](/docs/pedir/membros-arquivar-e-excluir).
