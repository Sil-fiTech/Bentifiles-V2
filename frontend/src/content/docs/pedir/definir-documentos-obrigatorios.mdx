A lista de documentos pedidos define o **checklist** de cada pessoa no projeto. Sem ela, o checklist fica vazio e ninguém tem o que enviar.

## Abrir as configurações

<Steps>

1. Abra o projeto.
2. Clique em **Configurações do projeto** (no cabeçalho, ao lado de **Convite**). Esse botão aparece só para quem administra o projeto.
3. Vá até o cartão **Configuração de Documentos**.

</Steps>

## Opção 1: aplicar um template

Em **Aplicar Template**, busque o modelo pelo nome, selecione-o na lista e confirme. O sistema mostra "Template aplicado com sucesso!".

<Callout type="info" title="O template só acrescenta">
Aplicar um template **adiciona** os documentos que o projeto ainda não tem. Ele **não remove** nem altera o que já estava marcado, e não duplica um documento que já existe no projeto. Isso significa que você pode aplicar mais de um template ao mesmo projeto.
</Callout>

Se o template tiver um documento que ainda não existe na sua lista de tipos, o sistema cria o tipo automaticamente.

## Opção 2: marcar documento por documento

Logo abaixo há a tabela com todos os seus tipos de documento. Marque a caixa dos que o projeto exige e desmarque os que não exige. Use a busca para achar um tipo pelo nome.

As mudanças valem para o projeto na hora e aparecem no checklist de cada pessoa.

## Dicas

- Se o tipo que você precisa não está na tabela, cadastre antes em [Tipos de documento e templates](/docs/pedir/tipos-de-documento-e-templates).
- Em projeto **arquivado** não dá para alterar a lista (o sistema avisa "Projeto arquivado").
