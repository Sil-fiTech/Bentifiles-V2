O painel é a primeira tela depois de entrar. Ele tem duas áreas: **Projetos Recentes** e **Inteligência dos Arquivos**.

## Menu superior

| Item | Para que serve |
| --- | --- |
| **Dashboard** | Volta ao painel. |
| **Novo Projeto** | Cria um projeto na hora. Veja [Criar um projeto](/docs/pedir/criar-um-projeto). |
| **Tipos & Templates** | Cadastra os tipos de documento e os modelos de projeto. Veja [Tipos de documento e templates](/docs/pedir/tipos-de-documento-e-templates). |
| **Afiliados** | Programa de indicação. Veja [Programa de afiliados](/docs/conta/programa-de-afiliados). |
| **Lâmpada** | Abre o [guia passo a passo](/docs/comecando/guia-na-plataforma) da tela. |
| **Seu avatar** | Perfil, assinatura, afiliados e sair da conta. |

No celular, esses itens ficam atrás do botão de menu (☰), no canto da tela.

## Projetos Recentes

Mostra os seus projetos, do mais novo para o mais antigo. Clique em um cartão para abrir o projeto.

- Use **Pesquisar projetos** para filtrar pelo nome.
- Projetos arquivados ficam ocultos. O botão **Mostrar Arquivados** os traz de volta, no fim da lista.
- A data no cartão é a de **criação** do projeto.

## Inteligência dos Arquivos

É o histórico recente de envios, com duas abas:

- **Meus documentos:** o que **você enviou**, com o resultado da validação.
- **Documentos para avaliar:** o que **outras pessoas enviaram** aos seus projetos e aguarda a sua decisão. O número ao lado do nome da aba é a quantidade de pendências.

### Os números

| Indicador | Significado |
| --- | --- |
| **Total de envios** | Todos os envios feitos por você, incluindo os barrados pela validação automática. |
| **Aprovados** | Passaram na validação ou foram aceitos por um revisor. |
| **Reprovados** | Barrados pela validação automática ou rejeitados por um revisor. |

### Os status de cada arquivo

| Status | Quando aparece |
| --- | --- |
| **PROCESSANDO** | O arquivo ainda não tem resultado de validação. |
| **APROVADO** | Passou na validação ou foi aprovado por um revisor. |
| **REVISÃO** | A validação não conseguiu decidir sozinha e pede uma olhada humana. |
| **REJEITADO** | Foi recusado. O **motivo** aparece no cartão do arquivo. |
| **PENDENTE** | (Aba *Documentos para avaliar*) Está esperando a sua decisão. |

### Barra "Processamento Ativo"

Aparece no canto da tela enquanto houver arquivos sem resultado de validação e mostra quantos ainda estão na fila.

<Callout type="tip">
Se um arquivo foi rejeitado, abra o projeto de origem para reenviar. O nome do projeto aparece no cartão do arquivo.
</Callout>

<Callout type="info" title="Participa de projetos, mas não tem assinatura?">
Quem só **participa** de projetos (sem assinatura própria) vê os projetos no painel e envia documentos normalmente, mas a área **Inteligência dos Arquivos** pode aparecer vazia, com os números zerados. Isso não significa que seus envios sumiram: eles ficam na **página de cada projeto**, em **Meus Documentos**.
</Callout>
